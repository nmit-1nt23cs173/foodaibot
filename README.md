# 🍽️ Food AI Chatbot

A web-based Food AI Chatbot that helps users discover meals, get food recommendations, browse menus, and simulate ordering using a conversational interface.

---

## 📌 Features

- AI-based food recommendations using user queries  
- Chat-based food search interface  
- Menu browsing by categories (Breakfast, Lunch, Dinner, etc.)  
- Add to cart functionality  
- Order summary generation  
- Simple and responsive UI  
- Restaurant/food filtering system
